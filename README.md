# Full Stack Open

My exercise solutions for the [Full Stack Open](https://fullstackopen.com/) course
(University of Helsinki).

## Structure

Each part gets a top-level directory. Parts that involve applications hold one standalone
app per exercise set, plus a `demo/` app for following along with the material — `demo/` is
scratch work and is never submitted.

| Part | Contents |
| --- | --- |
| [part0](part0/) | Fundamentals of web apps — Mermaid sequence diagrams |
| [part1](part1/) | Introduction to React — `demo`, `courseinfo`, `unicafe`, `anecdotes` |

Part 3 onwards is deployed, and the course asks for it in its own repository, so it will
not live here.
